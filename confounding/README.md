# Stage 2 Confounding Website

This folder is a no-build static website for the BRCAPath-Rx Stage 2 confounding prototype.

## Files

- `index.html`: main static website
- `confounding_demo_payload.json`: data payload generated by the Stage 2 analysis script
- `assets/`: local copies of generated figures used by the website

## Regenerate The Website Inputs

Run the Stage 2 pipeline from the repository root:

```powershell
python 07-stage2-confounding-prototype\02-scripts\01_stage2_causal_prototype.py
```

That command refreshes:

- `03-results/*`
- `04-website/confounding_demo_payload.json`
- `04-website/assets/*`
- `05-reports/*`

## Preview Locally

Serve the `07-stage2-confounding-prototype` folder, not just `04-website`, so relative paths stay valid:

```powershell
cd 07-stage2-confounding-prototype
python -m http.server 8000
```

Then open:

`http://localhost:8000/04-website/`

## GitHub Pages Note

The website is self-contained inside `04-website` because the required figures are copied into `04-website/assets/`. Publishing this folder as a static site is sufficient.
