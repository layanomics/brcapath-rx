## Build Strategy: Improve, Don't Fabricate

- Correct JavaScript math (identical to v2)
- Working live browser inference

The `demo_predictions.json` is shared (identical bytes, copied) — no model data was changed.

## Prediction Mode

**Live in browser from exported Cox payload.**

Exported to `demo_predictions.json`:
- Fitted Cox coefficients (TCGA and METABRIC)
- Model centering means (for centred linear predictor)
- Breslow baseline survival curves (1000+ timepoints per cohort)
- Cohort-specific control metadata (age ranges, subtype options, stage/NPI ranges)
- Default profiles for comparison curves
- Risk band thresholds (log partial hazard percentiles from training data)
- C-index values and subtype field labels

Calculated live in browser per user interaction:
- Linear predictor for selected profile
- Hazard ratio
- Predicted survival curve (baseline ^ HR)
- 3-year and 5-year survival estimates
- Risk band classification
- Plain-language interpretation text

**Yes.** The site:
- Uses only CDN-loaded libraries (Tailwind, Chart.js, Google Fonts)

- Loads `demo_predictions.json` via `fetch()` (requires HTTP serving — works on GitHub Pages, localhost HTTP server, or any static host)

```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`

## Caveats to Say Aloud During the Meeting

1. **Core statement:**
   > "This is a cohort-specific Stage 1 prognostic demo. It ranks relative survival risk within each
   > cohort using age, clinical, and molecular subtype features. It does not estimate treatment effects
   > and does not recommend treatment."

2. **On the two cohorts:**
   > "TCGA and METABRIC use different model inputs because the available data differ —
   > TCGA includes simplified stage, METABRIC uses the Nottingham Prognostic Index.
   > Both are valid for their cohort."

3. **On METABRIC subtypes:**
   > "METABRIC subtype now uses a derived PAM50 from public gene expression data,
   > not the original CLAUDIN_SUBTYPE field, which did not map to standard PAM50 categories."

4. **On treatment:**
   > "Treatment fields exist in both cohorts but are observational and incomplete.
   > Addressing treatment confounding is a later-stage question — not what this demo answers."

5. **On C-index interpretation:**
   > "A C-index of 0.73 means the model correctly orders about 73 out of 100
   > comparable patient pairs by relative risk. It is not a prediction of individual survival time."
