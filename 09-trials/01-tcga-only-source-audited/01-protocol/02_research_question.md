# Research Question Worksheet

## Main study question
Can TCGA-BRCA alone support a source-audited prognostic baseline workflow before any external validation?

## First-study objective
Build a clean TCGA-only cohort and determine whether the available TCGA clinical, biospecimen, treatment, and outcome data are sufficient for a defensible prognostic baseline study.

## First-trial framing
This first trial is a TCGA-only source-audited rebuild.
It is not a merged TCGA+METABRIC training design.
It is not a treatment recommendation study.
It is not a causal treatment-effect study.

## Intended first deliverable
A validated TCGA-only cohort inventory, variable audit, endpoint audit, and baseline prognostic analysis plan.

## Non-goals for this first trial
- no merged TCGA+METABRIC training cohort
- no treatment recommendation claims
- no causal treatment-effect claims
- no use of unclear or weakly traced variables

## Current working decisions
- study type: prognostic baseline study
- development dataset: TCGA-BRCA only
- external validation: deferred
- merged-cohort comparison: deferred until later stage
- source standard: only source-traceable variables allowed
