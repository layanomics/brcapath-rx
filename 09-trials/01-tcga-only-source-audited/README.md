# TCGA-Only Source-Audited Trial

## Goal
Build a fresh TCGA-BRCA-only, source-audited workflow from raw download to validated cohort construction.

## Rules
- no old generated data reused
- no merged TCGA+METABRIC starting point
- every derived table must trace back to source
- modeling only starts after cohort and variable audit are complete

## Planned phases
1. protocol
2. raw download
3. source audit
4. cohort construction
5. endpoint audit
6. baseline analysis
