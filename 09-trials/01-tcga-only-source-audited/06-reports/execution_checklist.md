# TCGA-Only Execution Checklist

## Stage 1
- finalize scientific question
- define unit of analysis
- define endpoint candidates
- define inclusion and exclusion rules

## Stage 2
- download TCGA clinical source files
- download TCGA biospecimen source files
- record manifests and download logs

## Stage 3
- parse source files into flat tables
- audit identifiers
- audit variable provenance
- review missingness before modeling
